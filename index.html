MedPrompt

Dynamic Semantic Aware Prompt Encoding for Medical Image Segmentation with MedSAM-2

MedPrompt is an interactive medical image segmentation demo built on MedSAM-2. Its Dynamic Semantic Aware Prompt Encoding (DSPE) combines local image context with learned foreground prototypes to improve segmentation accuracy and reduce sensitivity to click placement. The interface allows users to select a target with a point prompt and inspect the predicted segmentation for research and annotation exploration.

Jiaxi Hu

Abstract

Medical SAM 2 (MedSAM-2) supports medical image segmentation using point prompts, yet its initial point encoding does not incorporate the image context surrounding each click. We propose Dynamic Semantic Aware Prompt Encoding (DSPE) to enrich geometric point representations with local visual context and learned anatomical references. DSPE introduces an Anisotropic Context Encoding Module (ACEM), which aggregates horizontal and vertical features around each click and combines them with local image features to construct a query representing the surrounding context. Learnable anatomical prototypes are initialized from foreground features of the training data and optimized during segmentation training to provide semantic references for the segmentation target. The query guides prototype matching, while gated residual fusion integrates the matched references with the local representation. The resulting features calibrate the original point embedding before mask decoding, preserving geometric guidance while incorporating visual information from the image. Experiments on REFUGE, ISIC2018, and ACDC demonstrate improved segmentation accuracy over MedSAM-2, while evaluations with perturbed point prompts show reduced sensitivity to click placement.

Medical SAM 2（MedSAM-2）支持通过点提示进行医学图像分割，但其初始点编码未融合每次点击周围的图像上下文。我们提出动态语义感知提示编码（DSPE），利用局部视觉上下文和学习得到的解剖结构参考信息，增强几何点表示。DSPE 引入各向异性上下文编码模块（ACEM），聚合每次点击周围的横向和纵向特征，并将其与局部图像特征结合，构建表征周围上下文的查询。可学习的解剖原型由训练数据的前景特征初始化，并在分割训练过程中优化，为分割目标提供语义参考。查询引导原型匹配，门控残差融合将匹配到的参考信息与局部表示整合。所得特征在掩膜解码前校准原始点嵌入，在保留几何引导的同时融入图像中的视觉信息。REFUGE、ISIC2018 和 ACDC 上的实验表明，该方法相较于 MedSAM-2 提高了分割准确性；点提示扰动评估进一步显示，其对点击位置的敏感性有所降低。

Introduction & Demo

Point prompts provide a simple way to indicate a target in a medical image, but segmentation predictions can vary with the location of the click. MedSAM-2 initially represents each point using its position and prompt label, without explicitly incorporating the local image features surrounding that point. MedPrompt explores whether introducing this information during prompt encoding can improve segmentation quality and reduce sensitivity to click placement.

The proposed DSPE combines directional image context with learnable prototypes derived from training foreground features. Dynamic gating controls how these features contribute to the original point representation before mask decoding, while preserving the point-based interaction. The research evaluates this approach on optic cup segmentation, skin lesion segmentation, and cardiac MRI structures.

点提示让用户能够通过简单的点击指定医学图像中的目标，但分割结果可能随点击位置变化。MedSAM-2 的初始点表示使用位置和提示标签信息，未显式融合点击周围的局部图像特征。MedPrompt 探索在提示编码阶段引入这些信息，以提高分割质量并降低对点击位置的敏感性。

所提出的 DSPE 将方向性图像上下文与从训练数据前景特征中学习的原型相结合，通过动态门控控制这些特征对原始点表示的贡献，再进行掩膜解码，同时保留点提示交互方式。研究在视杯、皮肤病灶和心脏 MRI 结构分割任务上评估了这一方法。
